# Artigo 210.º

### (Inêxito das diligências para aplicação de uma medida de coacção)

1 - Para efeito de aplicação ou de execução de uma medida de coacção é correspondentemente aplicável o disposto no artigo 115.º

2 - Se o juiz tiver elementos para supor que uma pessoa pretende subtrair-se à aplicação ou execução da prisão preventiva, pode aplicar-lhe imediatamente, até que a execução da medida se efective, as medidas previstas nos artigos 198.º a 201.º, inclusive, ou alguma ou algumas delas.
