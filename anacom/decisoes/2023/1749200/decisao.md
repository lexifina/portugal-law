# Adjudicação de serviços de desenvolvimento de software do sistema para interação com o exterior relativo aos Serviços Radiocomunicações

Decisão de 2023-06-21 · publicado em 2023-08-08

Por decisão de 21 de junho de 2023, a ANACOM aprovou o relatório final do concurso público para prestação de serviços de desenvolvimento de software do sistema para interação com o exterior relativo aos Serviços Radiocomunicações e autorizou a adjudicação à Claranet II Solutions.
