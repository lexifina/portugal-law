# Artigo 36.º

### Transferências para capitalização

1 - Reverte para o FEFSS uma parcela até dois pontos percentuais do valor percentual correspondente às quotizações dos trabalhadores por conta de outrem.

2 - Os saldos anuais do subsistema previdencial, bem como as receitas resultantes da alienação de património, são transferidos para o FEFSS.
