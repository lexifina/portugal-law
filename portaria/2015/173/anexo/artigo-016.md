# Artigo 16.º

### Montante base apostado

1 - O montante base apostado consiste no valor que o apostador associa a cada combinação de prognósticos, consoante a modalidade de aposta escolhida.

2 - O montante base referido no número anterior é necessariamente compreendido entre (euro)1,00 e (euro)100,00, sem prejuízo do disposto no artigo seguinte.
