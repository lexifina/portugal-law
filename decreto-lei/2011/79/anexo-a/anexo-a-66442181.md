# Anexo A

### Laboratório nacional de referência

1 - O laboratório nacional de referência para as doenças aviárias, previsto no artigo 4.º, é responsável pela coordenação dos métodos de diagnóstico previstos no presente regulamento.

2 - O laboratório nacional de referência detém as seguintes atribuições:

a) Fornecer aos laboratórios aprovados os reagentes necessários para o diagnóstico;

b) Controlar a qualidade dos reagentes utilizados pelos laboratórios encarregados de efectuar os testes de diagnóstico previstos no presente regulamento;

c) Organizar periodicamente testes comparativos.
