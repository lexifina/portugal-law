# Correção das peças do concurso público para prestação de serviços Microsoft Enterprise Agreement, Microsoft Azure e Microsoft Unified Enterprise Support

Decisão de 2024-08-29 · publicado em 2024-09-02

Por decisão de 29 de agosto de 2024, a ANACOM aprovou a correção do programa e do caderno de encargos do concurso público para a subscrição de serviços de licenciamento Microsoft Enterprise Agreement, de serviços Microsoft Azure e para a prestação dos serviços de suporte Microsoft Unified Enterprise Support.
