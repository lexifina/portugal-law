# Prestação de serviços de desenvolvimento de software do sistema para interação com o exterior relativo aos Serviços Radiocomunicações

Decisão de 2023-04-13 · publicado em 2023-04-19

Por decisão de 13 de abril de 2023, a ANACOM aprovou o lançamento do concurso público, com publicidade internacional, para prestação de serviços de desenvolvimento de software do sistema para interação com o exterior relativo aos Serviços Radiocomunicações.

Foram igualmente aprovadas a constituição do júri e as peças do concurso (caderno de encargos e programa).
