# Consulta sobre plano de atividades para o triénio 2015-2017

Decisão de 2014-05-08 · publicado em 2014-05-13

Por deliberação de 8 de maio de 2014, a ANACOM aprovou o lançamento de uma consulta pública sobre as orientações estratégicas para o plano plurianual de atividades 2015-2017, fixando-se o prazo de vinte dias úteis para os interessados se pronunciarem.
